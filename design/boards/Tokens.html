Design tokens

Colour, type, space, radius, elevation, motion

Every value below is a CSS custom property that drops into the top of style.css. Colours are U.S. Web Design System (USWDS) system tokens wherever one passes; the few custom values are marked. Contrast ratios are measured with the WCAG 2.1 formula against the surface the colour sits on. Text needs 4.5:1 (3:1 at 24 px and above); borders and focus rings need 3:1. No USWDS code is loaded: these are the values, pasted into one stylesheet.

Type

Public Sans, the USWDS typeface (open licence, bundled as woff2 400/600/700 in /static/fonts), falling back to Segoe UI on locked-down Windows desktops. Numbers use font-variant-numeric: tabular-nums. Root is 17 px, the USWDS body size; at 125% browser zoom that is 21 px and every layout still fits 1280 px.

Headline 30/1.15--fs-6 · page titles
Banner 24/1.2--fs-5 · status banner headline
Section 20/1.3--fs-4 · card and section headings
Body 17/1.5, the default for reasons, forms and tables--fs-3
Body narrow 16/1.5, under 640 px--fs-2
Label 14/1.45 semibold: field labels, table headers--fs-1
Caption 13/1.4: timings, file names, identifier strip, never below this--fs-0
Mono 15 · 45% · 750 mL · 0.9 s · APP-0042--mono
