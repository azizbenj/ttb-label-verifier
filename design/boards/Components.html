Every component, every state

Each card shows the component as drawn in the screens, its anatomy and its accessibility contract. Sizes are in CSS px at 100% zoom; hit targets are 44 px minimum, 36 px only inside dense table rows that are themselves 40 px tall.

Verdict chips

MATCH NEAR MATCH MISMATCH NOT FOUND SKIPPED
PASS REVIEW FAIL Match Near Mismatch Not found Skipped

Anatomy. Glyph 14 px + word, 13 px bold, 28 px tag with 3 px corners (USWDS tag, not a pill), 1 px line, tint fill. Mini: 22 px, 12 px, sentence case, for the dense table only. Glyphs are fixed per verdict (check, exclamation, cross, question, dash) so colour is never the only signal; NOT FOUND shares FAIL colours but keeps the question glyph. Semantics. A plain <span>; the word is the accessible name, the SVG is aria-hidden. Never clickable on its own.

Word-level. Each diff item is shown inside five words of context so the agent reads the sentence, not a fragment. The differing word is bold, coloured and wavy-underlined (three signals). "(nothing)" marks a missing word. Rows map 1:1 onto w.diff; the context comes from the mandated text's word index.

Sample picker (gallery)

Four clean labels as thumbnails, then one tile that opens the eleven defect samples (grouped: fields, warning). Choosing one fills the form and the preview in one step, exactly as the <select> does today; the select stays in the DOM, visually hidden, as the no-JS and screen-reader path, and the tiles are aria-pressed buttons that set it.

Buttons, inputs, focus

Please fill in the net contents, e.g. 750 mL.

Primary (action fill), secondary (white, action border), quiet (text), danger (fail outline, confirms before acting). 44 px min; "big" 52 px for the two form submits. Disabled keeps its label and shows what is happening ("Checking…"). Inputs 44 px, 16 px text, 1 px line-strong border (3.25:1); invalid = 2 px fail border, aria-invalid, message linked by aria-describedby. Focus is one ring everywhere: 3 px action, 2 px offset, never removed, visible on every ground in both themes.
